# Reality Stack · 现实技术栈

A bilingual, civilization-scale cinematic essay arguing that reality is a layered system. Ten layers — Physics, Energy, Matter, Life, Intelligence, Civilization, Information, Simulation, AI, Meta-Reality — each running on the substrate of the ones below and enabling the ones above.

## Links

- **Live:** [reality-stack.psyverse.fun](https://reality-stack.psyverse.fun)
- **GitHub:** [github.com/gewenbo888/reality-stack](https://github.com/gewenbo888/reality-stack)

## Stack

- Next.js 14 (App Router, `src/app/`)
- React 18 + TypeScript
- Three.js — WebGL cosmic field (starfield → 10-layer stack as you scroll)
- SVG — Layer stack diagram with animated dependency arrows
- Framer Motion — scroll-reveal choreography
- Tailwind CSS with a custom 10-tier accent palette (L0..L9)
- Fonts: Cormorant Garamond display + Inter Tight body + JetBrains Mono HUD + Noto Serif SC
